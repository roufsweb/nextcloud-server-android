A True Linux Server in Your Pocket

Designed from the ground up to utilize your phone's multi-core ARM processor, fast UFS flash, and low idle power consumption.

Native Linux Stack

No chroot, proot, or virtual machine emulation. Compiled native ARM64 Nginx 1.24, PHP-FPM 8.2, and SQLite 3 run straight on Android Bionic for maximum efficiency.

Hot-Plug External Drives

Plug in a MicroSD card or USB OTG SSD formatted in FAT32, exFAT, NTFS, or ext4. The storage engine discovers and mounts volumes automatically into your Nextcloud root.

Camera Auto-Upload

Fully compatible with official Nextcloud Android and iOS clients. Seamlessly back up your smartphone photos and videos wirelessly as soon as you connect to your home Wi-Fi.

Data Safe from Uninstall

Removable SD card data is independent hardware storage. Files uploaded to external drives are never wiped when updating or uninstalling the server app.

Partial WakeLock & Boot

Maintains persistent CPU execution through Android battery saving modes so file transfers never drop. Optionally starts server automatically on device reboot.

Material 3 Control Center

Real-time server telemetry, port modification (1024–65535), trusted host configuration, and fine-grained administrator password controls with live progress feedback.

Default Administrator Credentials

Upon initial launch, Nextcloud automatically provisions a default administrator account. You can log in immediately or customize credentials inside the Settings & System tab.

Got Questions?

Frequently Asked Questions

Everything you need to know about running a self-hosted cloud on Android.

Does Nextcloud Server for Android require root access?
No root is needed. The server stack runs completely within regular Android application sandbox permissions using non-privileged user ports (default 8000 or 8080).
Which Android versions are supported?
Nextcloud Server for Android supports Android 8.0 (API 26) through Android 17. The native binaries are packaged with full 16 KB memory page size alignment (required for Android 15, 16, and 17 kernels) and conform strictly to modern SELinux W^X execution constraints without requiring root access.
Does deleting or updating the app delete my uploaded files on the SD card?
No, never. External MicroSD cards and USB OTG drives are treated as independent hardware media. Your uploaded photos, documents, and directories reside directly on the physical storage filesystem and are never touched when uninstalling or updating the APK.
What are the default login credentials?
The initial administrator username is admin and the default password is NextcloudAdmin123!. You can change these anytime in the Settings & System tab.
Can I connect to my server from outside my home Wi-Fi?
Yes. You can expose your phone's Nextcloud server to the internet using Cloudflare Tunnels (cloudflared), Tailscale, WireGuard, or a reverse proxy. Just remember to add your custom domain to the Trusted Domains list in the app.
Can I install the APK directly without unzipping?
Yes! Starting in v1.0.0, the app is packaged and distributed directly as a standalone .apk (~391.9 MB). Simply download and tap to install without any extra extraction steps.
